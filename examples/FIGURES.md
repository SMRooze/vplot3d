# Thesis figures: ship-towing kite (wind window and pumping cycle)

These scripts generate the figures and animations of a thesis on ship-towing kites,
built with `vplot3d`. They live in this fork next to the original examples of the library.

## Setup

From the repository root, follow the installation steps in the main [README](../README.md), then:

```bash
pip install -e .
pip install -r examples/requirements-figures.txt
```

- No Inkscape or xelatex is needed: labels are rendered with matplotlib mathtext, PNGs with
  `resvg-py`, and videos with the ffmpeg binary bundled in `imageio-ffmpeg`.
- The **PDF** export of Figs. 3.1 and 3.3 (`thesis_export.py`) prints the SVG with a headless
  **Microsoft Edge or Google Chrome**, so one of the two must be installed (looked up in the
  default Windows install locations, then on `PATH` as `msedge` / `chrome`).

Run every script **from the `examples` folder**, because they read sibling scripts and layout
files by relative path:

```bash
cd examples
python figure_3_1_powered_crosswind_geometry.py
```

Each script writes to its own output folder inside `examples/`. These folders are not
tracked by git.

## Scenes and animations

| Script | What it makes | Output folder |
|---|---|---|
| `wind_window.py` | Wind window with figure-eight path, static figures and 48-frame kite loop | `wind_window/` |
| `wind_window.py --axes` | Same, with the kite's e_r and e_t unit vectors | `wind_window_axes/` |
| `wind_window.py --axes --phirep` | Same, with the representative QSM state | `wind_window_axes_phirep/` |
| `wind_window.py --axes --phirep --sweep phic\|beta` | Sweep of the pattern centre azimuth or elevation | `wind_window_axes_phirep_sweep_*/` |
| `wind_window.py --sweep alpha` | Sweep of the angle of attack | `wind_window_sweep_alpha/` |
| `wind_window_phic.py [--phirep]` | Sweep of phi_c with phi_QSM,rep recomputed per frame | `wind_window_phic[_phirep]/` |
| `pumping_cycle.py [--view side\|side3d\|oblique\|upwind] [--stills]` | Pumping cycle in 3D, one clip per phase | `pumping_cycle[_view_*]/` |
| `presentation_pumping_cycle.py [--stills]` | Presentation clips per phase and a seamless full loop | `pumping_cycle_presentation/` |

Add `--no-anim` to `wind_window.py` to skip the animation, or `--stills` to the pumping cycle
scripts for a quick layout check. Full animation runs take several minutes.

## Supporting files

- `thesis_export.py`: SVG to PNG (resvg) and SVG to vector PDF (headless Edge/Chrome).
- `pumping_cycle_layouts.json`, `wind_window_sweep_layout.json`: tuned label positions, read
  automatically. They are regenerated by `pumping_cycle.py --layout` and
  `wind_window.py --axes --phirep --sweep phic --sweep-layout`; there is no need to rerun these.
- The 3D kite model is `data/kiteV3.py` from the original repository.
